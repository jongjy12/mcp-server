    ### 🧪 Automated Unit Testing for Changes

    When asked to "Perform unit testing for my changes":

    1. Analyze Changes  
       - Use `mcp_execute_git` with `diff HEAD`

    2. Plan Scenarios  
       - Map changes to APIs, business rules, edge cases

    3. Prep Data  
       - Use `mcp_execute_sql` to query or prepare test data

    4. Execute Tests  
       - Use `mcp_call_api` to simulate requests

    5. Monitor Logs  
       - Use `mcp_get_live_log` with project-specific `log_path`
